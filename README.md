# Códigos de Tesis de Maestría

Este repositorio contiene los códigos desarrollados para la tesis:

**Localización de una fuente RF mediante mediciones RSSI y estimación del ángulo de llegada utilizando un dron cuadricóptero autopiloteado**

## Organización del repositorio

- `Capítulo 3/`: código relacionado con la comunicación entre dos PC mediante los MRAPC.
- `Capítulo 4/`: código desarrollado para la visualización y filtrado de mediciones RSSI.
- `Capítulo 5/`: códigos correspondientes a la estación terrenal y a la estación móvil desarrolladas para la adquisición de patrones de radiación basados en RSSI.
